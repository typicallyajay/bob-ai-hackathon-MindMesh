02 / The Solution

Deterministic Reconstruction + Conversational AI

THREATMESH ingests multi-source raw alerts and reconstructs coherent, explainable attack narratives:

Deterministic Core

  • Entity-Anchored Correlation: Clusters via Union-Find and multi-dimensional similarity.
  • MITRE ATT&CK Mapping: Strict deterministic technique identification backed by alert IDs.
  • Bifurcated Scoring: Threat Score (danger) and Confidence (evidence strength) separated.

Explainable AI Layer

  • Counterfactual Analysis: "What if alert X is false?" Real recalculation and impact delta.
  • Interactive Attack Graph: Directed entity visualization (NetworkX + React Flow).
  • IBM Bob Assistant: Conversational SOC copilot with real application tool binding.

05 / IBM Integration

IBM Bob as Load-Bearing Tool Operator

IBM Bob does not guess security facts. Bob executes genuine application tools against the deterministic engine:

  • get_incidents() — Retrieves sorted incident queue with threat metrics.
  • get_evidence(incident_id) — Queries evidence items and importance tags.
  • get_attack_graph(incident_id) — Retrieves entity topology and lateral transitions.
  • run_counterfactual(incident_id, alert_id) — Executes mathematical re-scoring on reduced evidence.
  • generate_bluf(incident_id) — Structures Bottom Line Up Front commander briefing.

Complete transparent audit logging tracks all tool calls made during investigations.
