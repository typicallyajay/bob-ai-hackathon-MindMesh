01 / The Problem

Alert Fatigue & Fragmented Telemetry

80–95%

False Positives: Enterprise SOCs receive 400+ disconnected alerts daily from SIEM, EDR, network, DNS, and auth tools.

40+ Mins

Lost Time Per Alert: Analysts manually cross-reference IP addresses, hostnames, and user credentials across isolated dashboards.

  • Fragmented Attack Paths: Multi-stage breaches appear as 3–7 isolated logs with zero narrative linking initial access to data exfiltration.
  • Black-Box LLM Hallucinations: Standard chatbots invent non-existent CVEs and numerical risk scores without verifiable telemetry backing.

02 / The Solution

Deterministic Reconstruction + Conversational AI

Deterministic Core

  • Multi-Source Correlation: Clusters raw alerts across identity, host, IP, and temporal similarity.
  • MITRE ATT&CK Mapping: Strict technique identification backed by verifiable alert IDs.
  • Bifurcated Scoring: Threat Score (danger) and Confidence (evidence strength) kept strictly independent.

Explainable AI Layer

  • Counterfactual Threat Analysis: "What if this alert is false?" Recalculates scores live and tests chain integrity.
  • Interactive Attack Graph: Reconstructs visual entity topologies using NetworkX and React Flow.
  • IBM Bob Investigation Partner: Real tool access (`get_incidents`, `get_evidence`, `get_attack_graph`).

05 / IBM Bob Integration

IBM Bob: Conversational SOC Partner

IBM Bob does not recite canned answers. Bob executes genuine application tools against the deterministic engine:

  • get_incidents() — Retrieves ranked incident queue
